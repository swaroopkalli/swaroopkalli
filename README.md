**Python · FastAPI · PostgreSQL · RAG · LLMs**

- Built a closed-loop backend that processes medication, mood, sleep, and symptom data to identify potential adherence risks.
- Implemented a hybrid decision pipeline combining deterministic rules, stress scoring, and RAG-based contextual analysis.
- Designed role-based workflows for patients, caregivers, and doctors with targeted alerts and summarized insights.
- Developed the system as a modular FastAPI backend with PostgreSQL for structured user and health-event data.

### 🥤 Beverage Composition & Recommendation System
**Python · FastAPI · PostgreSQL · LLMs**

- Built an LLM-powered recommendation backend that processes user preferences, available ingredients, and contextual inputs.
- Implemented a multi-stage pipeline for preference extraction, ingredient normalization, substitution, reasoning, and drink composition.
- Structured the backend into modular services so recommendation criteria and knowledge sources can be extended independently.
- Exposed the recommendation pipeline through REST APIs using FastAPI with PostgreSQL for persistent data.
